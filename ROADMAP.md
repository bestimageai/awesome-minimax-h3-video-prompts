# Roadmap

Help the bestimage.ai team expand the library with practical examples and useful production guidance.

## Example coverage

- Share videos generated from the library's prompts, together with settings and reference roles.
- Compare text, image, video and audio inputs where the selected workflow supports them.
- Contribute before-and-after examples for editing, continuation and camera direction.

## Creative workflows

- Add scenarios for product demonstrations, tutorials, character performance and multilingual dialogue.
- Share methods for continuity, subtitles, accessibility and delivery review.

## Languages and documentation

- Improve localized examples and expand language coverage.
- Keep API and deployment guidance aligned with official documentation.
- Report broken links and unclear instructions.

See [CONTRIBUTING.md](CONTRIBUTING.md) to propose an addition.
