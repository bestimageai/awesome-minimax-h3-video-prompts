## O que você encontra

- 100 prompts audiovisuais em inglês, distribuídos em 21 categorias de produção;
- Estruturas orientadas ao H3 para referências de imagem, vídeo e áudio;
- Regras de continuidade para identidade, produto, figurino, cenário e direção de tela;
- Modelos para anúncios, produtos, UI, animação e redes sociais;
- Páginas de apresentação README em oito idiomas;

- Um [guia de prompts multilíngues](./docs/multilingual-prompting.md) com oito exemplos em idiomas diferentes do inglês e explicações em inglês, não traduções completas dos prompts para nove idiomas.

## Uso com bestimage.ai

- **Gerar vídeos:** Consulte a [página da API do MiniMax H3 na bestimage.ai (em inglês)](https://bestimage.ai/models/minimax/minimax-h3-text-to-video/) para acessar a geração de vídeos.
- **Preparar imagens de referência e quadros iniciais:** Consulte a [página da API do GPT Image 2 na bestimage.ai (em inglês)](https://bestimage.ai/models/openai/gpt-image-2/). O GPT Image 2 gera imagens, não os vídeos do H3.
- O [guia do fluxo de trabalho com as APIs](./docs/api-workflow.md) explica como combinar essas duas etapas. Consulte as páginas dos modelos para obter as informações atuais de conexão e das solicitações.

## Contribuições e estado dos testes

**Contribuições abertas:** Siga o [guia local de contribuição](./CONTRIBUTING.md) para propor um prompt H3 original que resolva um problema de produção. O vídeo final é opcional; informe as funções das referências, a linha do tempo, a continuidade, o som e o estado dos testes.

Os 100 prompts desta edição são pontos de partida para experimentar, não uma comprovação de resultados garantidos. As nove novas imagens —uma capa e oito exemplos— foram criadas com a ferramenta integrada de geração de imagens. São conceitos visuais estáticos, não resultados do H3 nem quadros extraídos de vídeos testados com o H3.

Este repositório é um projeto comunitário independente e não é um projeto oficial da MiniMax. Consulte capacidades e entradas na [documentação oficial do H3](https://platform.minimaxi.com/docs/guides/video-prompt).
